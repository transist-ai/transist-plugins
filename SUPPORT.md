# Support

Repository visibility does not imply unlimited public support, free consulting,
or an open-ended community support commitment.

## What To Open

- Use the [repository issue tracker](https://github.com/transist-ai/transist-plugins/issues), when available, for reproducible plugin defects,
  documentation corrections, and focused plugin proposals.
- The listed general-inquiry contact is <hello@transist.ai>; email delivery has
  not been verified for this publication.
- Implementation and support agreements are available separately.

## What To Expect

- Reproducible package defects are in scope.
- Documentation corrections are in scope.
- Focused package, integration, and compatibility proposals are in scope when
  aligned with this repository's documented package contract.
- Feature discussions are not commitments or roadmap promises.

## What Not To Expect

- Bespoke architecture design, free implementation work, guaranteed
  prioritization, and open-ended consulting are out of scope unless covered by
  a separate agreement.

## Security Issues

Do not report vulnerabilities in a normal issue. Follow
[`SECURITY.md`](SECURITY.md) for private reporting availability and email limitations.

## Before Opening An Issue

- Read [README.md](README.md) for the repository boundary.
- Check [CONTRIBUTING.md](CONTRIBUTING.md) for contribution expectations.
- Use the repository issue forms so reports include the details needed to act
  on them.
